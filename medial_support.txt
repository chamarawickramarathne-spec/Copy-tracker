# SmartCopy — Media Support File

1. Title
   SmartCopy — Intelligent File Transfer for Windows

2. Short description
   SmartCopy turns boring Windows copy/paste into a lightning-fast, auto-renaming smart transfer. Copy any files, press Ctrl+V in a folder, and SmartCopy does the rest — no dialogs, no waiting.

3. Long description
   SmartCopy is a high-performance Windows file transfer tool that upgrades the default copy/paste flow. Copy one file or a whole folder of photos in Explorer, press Ctrl+V in any destination folder, and SmartCopy instantly starts a blazing-fast transfer that streams with pooled buffers and parallel I/O — your screen never freezes. Files are renamed automatically, and you pick the naming format: name_folder_number (photo_Vacation_3.jpg), name folder number (photo Vacation 3.jpg), or folder number (Vacation 3.jpg). Every file keeps a unique, meaningful name, even when you paste many files at once, and numbers always continue from the file count so no two files ever share a number. A sleek, animated mini-player widget tracks progress, speed, and time remaining in real time, and can expand into a full detail view showing each file being copied. It runs quietly in the system tray, can start with Windows, and its Fluent dark interface is built for Windows 11. SmartCopy turns the most routine computing task into something fast, smooth, and genuinely satisfying.
