# SmartCopy — Media Support File

1. Title
   SmartCopy — Intelligent File Transfer for Windows

2. Short description
   SmartCopy turns boring Windows copy/paste into a lightning-fast, auto-renaming smart transfer. Copy or cut any files, press Ctrl+V in a folder, and SmartCopy does the rest — no dialogs, no waiting, now with instant paste response.

3. Long description
   SmartCopy is a high-performance Windows file transfer tool that upgrades the default copy/paste flow. Copy or cut one file or a whole folder of photos in Explorer, press Ctrl+V in any destination folder, and SmartCopy instantly starts a blazing-fast transfer that streams with pooled buffers and parallel I/O — your screen never freezes. Version 1.0.15 makes the whole paste path feel instant: destination folders are scanned once per batch instead of once per file (huge speedup on big or cloud-synced folders), the global keyboard hook stays feather-light so your typing is never delayed, progress updates are throttled so even NVMe-speed copies can't stutter the UI, and Explorer window detection runs off the UI thread. Cut+paste properly moves files: the source is deleted after a successful copy, so your clipboard intent is honored. Files are renamed automatically, and you pick the naming format: name_folder_number (photo_Vacation_3.jpg), name folder number (photo Vacation 3.jpg), or folder number (Vacation 3.jpg). Every file keeps a unique, meaningful name, even when you paste many files at once, and numbers always continue from the file count so no two files ever share a number. A sleek, animated mini-player widget tracks progress, speed, and time remaining in real time, and can expand into a full detail view showing each file being copied. It runs quietly in the system tray, can start with Windows, and keeps itself up to date automatically — a reliable built-in updater pulls the latest version straight from the official release, so every install is always current. Its Fluent dark interface is built for Windows 11. SmartCopy turns the most routine computing task into something fast, smooth, and genuinely satisfying.
